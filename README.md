# Teste-Arthur

Repositório de testes.

## Sobre

Este repositório é usado para praticar o fluxo de trabalho com Git e GitHub:
criar branches, fazer commits e abrir pull requests.

## Como usar

1. Clone o repositório:

   ```bash
   git clone https://github.com/arthurmdeoliveira21-dotcom/Teste-Arthur.git
   ```

2. Crie uma branch para sua alteração:

   ```bash
   git checkout -b minha-alteracao
   ```

3. Faça suas mudanças, crie um commit e abra um pull request.
